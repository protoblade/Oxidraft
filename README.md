# Oxidraft

**Open-source 2D drafting in Rust, in the spirit of AutoCAD LT.**

Oxidraft is a 2D-only CAD app that should feel familiar to anyone who drafts in
AutoCAD LT: a ribbon, a command line with aliases and AutoComplete, object
snaps, polar tracking, dynamic input, grips and window/crossing selection, and
DWG and DXF files. The goal is to cover the commands that make up most day-to-day 2D
work (LINE, PLINE, OFFSET, TRIM, FILLET, LAYER, DIM, HATCH…).

> Status: early prototype (v0.10). Expect breaking changes.

## What works today

| Area | Supported |
|---|---|
| Draw | `LINE` (`L`), `PLINE` (`PL`) with tangent Arc / Second pt / Close / Undo, Width / Halfwidth (tapered segments) and Length, `CIRCLE` (`C`), `ARC` (`A`) by three points or Center/Start/End/Angle, `RECTANG` (`REC`) by corners or Dimensions, `POLYGON` (`POL`) inscribed, circumscribed or by Edge, `ELLIPSE` (`EL`) by axis or Center, with Rotation, and elliptical Arcs, `SPLINE` (`SPL`) through fit points or by control vertices (Method), open or Closed, `XLINE` (`XL`) with Hor/Ver/Ang/Bisect/Offset and `RAY`, `DONUT` (`DO`), `REVCLOUD` around a rectangle or polygon or from an Object, Normal or Calligraphy (`REVCLOUDPROPERTIES` changes a cloud's arc length or style, or makes it a plain polyline), `POINT` (`PO`) drawn in the `PDMODE`/`PDSIZE` style, `DIVIDE` (`DIV`) and `MEASURE` (`ME`) placing points or blocks along an object, `SOLID` (`SO`) filled triangles and quadrilaterals, `SKETCH` freehand lines (as polylines, lines or splines, a point each record increment), `TRACE` solid lines of a width; `FILL` shows fills and wide polylines as outlines, `QTEXT` text as boxes; `LIMITS` sets the drawing limits, with ON refusing points outside them (all kept in DXF and DWG) |
| Annotation | `MTEXT` (`T`) in a box with Height/Rotation/Width and `\P` paragraphs, single-line `TEXT` (`DT`), `DIMLINEAR` (`DLI`, horizontal/vertical from the cursor, or Rotated) and `DIMALIGNED` (`DAL`) with text override, `DIMCONTINUE` (`DCO`) and `DIMBASELINE` (`DBA`), `DIMRADIUS` (`DRA`), `DIMDIAMETER` (`DDI`), `DIMANGULAR` (`DAN`: two lines, an arc, a circle or three points), `MLEADER` (`MLD`); `DIMORDINATE` (`DOR`, X or Y by a leader), `DIMARC` (`DAR`, an arc's length), `DIMJOGGED` (`DJO`, a large radius from a stand-in center), `QDIM` (the points of several objects at once, continued or from a baseline), `CENTERMARK` (`CM`) and `CENTERLINE` (`CL`, grouped center lines; arc length and jogged dimensions are saved as their drawn parts); `TABLE` (`TB`): the Insert Table dialog sets its columns, rows and sizes, then it's placed and filled in, a title row over a header row and data rows; double-click it (or `TABLEDIT`) to edit its cells and add or delete rows and columns, and Properties sets its column width, row height and text height (DWG and DXF files get its lines and text); text, dimensions, leaders and tables move, rotate, scale, stretch and edit in the Properties palette. `DIMSTYLE` (`D`) sets the drawing's dimension style (text height, arrow size, extension line offset and extension, text gap, precision, and DIMSCALE), kept in DWG and DXF; `FIND` finds and replaces text in text, leaders, attributes, dimension overrides and tables; `SPELL` (`SP`), the Check Spelling dialog, checks them against the system's word list (with plurals and other endings) and your own words (Add to Dictionary), suggesting corrections to Change or Change All, or Ignore; `SCALETEXT` gives text a new height or scales it, `JUSTIFYTEXT` hangs it from another point without moving it. The Annotate tab has them all, with Revision Cloud; `DIM` dimensions whatever is picked — a line (horizontal, vertical or aligned by where the dimension goes; a second line makes it the angle between), a circle (diameter) or arc (radius, toggled), or two points — and goes on until Enter, with Angular, Baseline, Continue, Ordinate, aliGn (onto a base dimension's line), Distribute (evenly spaced), Layer (DIMLAYER) and Undo; `DIMSPACE` spaces parallel dimensions by a distance or Auto; `DIMEDIT` (`DED`) puts text Home, gives New text, Rotates it or slants extension lines (Oblique); `DIMTEDIT` moves a dimension's text (its line follows) or sets it Left, Right, Center, Home or at an Angle; `DIMBREAK` cuts gaps where objects cross a dimension (Auto, one object, Manual, Remove). Dimensions follow the objects they measure (`DIMASSOC` 2): drawn on an object's endpoint, midpoint, center, quadrant, node or insertion point, or on a circle, they change as it moves or stretches, kept as AutoCAD's DIMASSOC in DXF and DWG and read from AutoCAD's; `DIMREASSOCIATE` (`DRE`) associates dimensions again, `DIMDISASSOCIATE` (`DDA`) stops them, `DIMREGEN` updates them all. `DIMINSPECT` (the Inspection Dimension dialog, or `-DIMINSPECT`) puts a round or angular frame around a dimension's text with a label and inspection rate. Moved and turned text and oblique extension lines are kept in DXF and DWG, overrides as AutoCAD's own (DSTYLE), and breaks, jogs and inspection data as Oxidraft's XDATA; `TOLERANCE` (`TOL`): AutoCAD's Geometric Tolerance dialog — the 14 GD&T symbols, two tolerances with Ø and a material condition, three datums, two rows — places a feature control frame (TOLERANCE in DXF and DWG); `DIMJOGLINE` jogs a linear dimension's line, `DIMOVERRIDE` sets DIMTXT, DIMASZ, DIMEXO, DIMEXE, DIMGAP or DIMDEC on selected dimensions alone and `DIMUPDATE` puts them back to the style; `MLEADERSTYLE` (`MLS`) sets the multileader arrowhead (closed filled, open, dot, none) and its size, the content — text (its height) or a tag block (circle, box, hexagon, triangle or slot, AutoCAD's `_TagCircle` and the rest, with a tag number) — and landing; `MLEADER`'s Options choose the content for one (Block takes any block with an attribute); Multileaders are kept as AutoCAD's MULTILEADER (DWG 2007 and later, DXF), AutoCAD's own coming in as one multileader each, with their text, blocks and every leader line; `MLEADEREDIT` (`MLE`) adds arrowheads to a multileader or removes them, `MLEADERALIGN` (`MLA`) lines their text up, `MLEADERCOLLECT` (`MLC`) gathers multileaders' blocks onto one in a row, a column or rows of a width; multileaders come back from Oxidraft's DXF and DWG whole (AutoCAD sees a LEADER with its text or blocks); `TABLESTYLE` (`TS`) sets new tables' text height and cell margin. The styles are kept in DWG and DXF (in an OXIDRAFT_SETTINGS record). Annotation scaling: text, dimensions, leaders, tolerances, hatches and blocks made annotative (the Properties palette's Annotative, or drawn in an annotative text, dimension or multileader style, whose sizes are then on paper) keep the scales they support; the status bar's annotation scale (`CANNOSCALE`) sizes them for it, each layout viewport shows them at its own scale on screen and in plots, `OBJECTSCALE` adds or deletes their scales, `ANNOAUTOSCALE` adds a new current scale to them, `ANNOALLVISIBLE` shows or hides those without it and `ANNOUPDATE` resizes them (kept in DXF and DWG); `SCALELISTEDIT` adds scales of your own to the list; a text's or block's grip moves only the current scale's representation, and `ANNORESET` puts the others back with it. `TEXTEDIT` (`ED`, or double-click text) opens text in the Text Editor; `FIELD` (Insert tab, or Insert Field in the editor) puts in AutoCAD's fields — the date, creation, save and plot dates in any date format, the file name or path, the title, author and other drawing properties, the login, or an object's area, length, radius or layer — which show their values as they're drawn and plotted (`UPDATEFIELD` finds them) and are saved as AutoCAD's FIELD objects in DWG and DXF (AutoCAD 2004 on; earlier versions get the values) |
| Text styles | `STYLE` (`ST`, or the Annotate tab's Text panel title): AutoCAD's Text Style dialog — styles with a font, which text shows and plots in: a TrueType or OpenType font found among the system's fonts or beside the drawing (Windows' arial.ttf, times.ttf and the like find their macOS and Linux counterparts), or an SHX font, read from AutoCAD's own files where AutoCAD is installed (or beside the drawing) and drawn as its strokes (simplex.shx stands in for one that's missing, as FONTALT does; without any, text shows in Oxidraft's typeface), with Use Big Font's big font (bigfont, extfont, gbcbig, chineset, whgtxt) drawing the Asian characters the main font lacks; PDF plots embed the TrueType fonts used, a fixed height or 0, width factor and oblique angle, with a preview; Set Current, New, Delete, Apply. `TEXT` and `MTEXT` use the current style (and its Style option); a fixed height isn't asked for. The Annotate tab's Text Style dropdown sets the current style, or restyles the selected text; the Properties palette edits a text's width factor and obliquing. Text draws, previews and plots narrow, wide or slanted as set. MTEXT's inline formatting shows and plots alike: fonts (`\f` with bold and italic faces, `\F` SHX fonts), heights, colors, width factor, obliquing, tracking, underline, overline and strikethrough, in SHX-font text too. Text is picked and zoomed to by its box measured in its font. `-STYLE` at the command line; `RENAME` and `PURGE` take text styles too. Kept in DWG and DXF |
| Hatch | `HATCH` (`H`): pick inside any enclosed area — even one formed by separate overlapping lines — and islands inside are left out; or select closed objects. Patterns SOLID, ANSI31, ANSI37, LINE, NET with scale and angle; hatches draw behind other objects. `HATCHEDIT` (`HE`): pattern, scale and angle, draw order (behind or in front of its boundary, back, front), boundaries added or removed, polylines made of them again (recreate Boundary), or separate areas made separate hatches; `HATCHGENERATEBOUNDARY` draws polylines along hatches' boundaries, `HATCHSETBOUNDARY` gives a hatch new boundaries from closed objects, `HATCHSETORIGIN` moves where its pattern starts (kept in DXF and DWG). `GRADIENT` (`GD`) fills with AutoCAD's nine gradients (LINEAR, CYLINDER, SPHERICAL, HEMISPHERICAL, CURVED and their inverses — also as HATCH patterns) between two colors at an angle, shaded smoothly on screen and in plots, kept in DXF and DWG (from AutoCAD 2004's format; 2000's has none, so a solid fill there); the Properties palette sets their colors. `BOUNDARY` (`BO`) draws closed polylines around an area picked inside |
| Blocks | `BLOCK` (`B`) turns objects into a block reference, `INSERT` (`I`) with Scale/Rotate and a live preview, `EXPLODE` (`X`) one level; `BEDIT` (`BE`, the Block panel's Edit, or double-click a block) opens a block in the Block Editor on its own, its base point at the origin, with Save Block (`BSAVE`) and Close Block Editor (`BCLOSE`, which asks before throwing changes away); the Blocks palette (`BLOCKSPALETTE`, the ribbon's Insert) shows this drawing's blocks as previews to click and place, and a library folder of DWG and DXF drawings whose blocks, or whole drawings, come in with their layers and the blocks they nest; `ADCENTER` (`ADC`, Cmd+2), DesignCenter, browses folders of drawings (and this one) for their blocks, layers, linetypes, text styles, xrefs and layouts, inserting blocks and bringing in layers, linetypes and text styles; `TOOLPALETTES` (`TP`, Cmd+3) keeps palettes of tools — commands (on a layer, in a color), hatch patterns, blocks — made from the selected objects or typed commands, in palettes of your own; references move, rotate, scale and mirror like any object; attribute definitions (`ATTDEF`, `ATT`: tag, prompt, default, invisible or constant) go into blocks with BLOCK, and INSERT then asks for each value; `ATTSYNC` gives a block's references the attributes it now defines, keeping their values; `ATTREDEF` redefines a block from new objects and does the same; definitions are kept in DWG and DXF; attribute values edit in the Enhanced Attribute Editor (`EATTEDIT`, or double-click the block); `ATTDISP` shows them as set, all, or none. `XCLIP` (`XC`) shows only part of a block reference or xref: inside (or with Invert clip, outside) a rectangle, polygon or polyline, with ON/OFF, Delete and generate Polyline; the boundary moves with the reference, its frame shows on screen but doesn't plot, and it's saved as AutoCAD's spatial filter in DXF and DWG. `CLIP` (the Insert tab's Clip) clips whatever is picked: a reference, an image or a PDF. `REFEDIT` (Insert tab, or Edit Block/Xref In-place on the right-click menu) edits a reference where it sits: the rest of the drawing fades and can't be selected, what you draw joins the working set, `REFSET` (Add/Remove) moves objects in or out, and `REFCLOSE` (the Edit Reference panel's Save or Discard Changes) redefines the block, updating every reference, or throws the edits away; `WBLOCK` (`W`, also on the Insert tab): AutoCAD's Write Block dialog writes a block, the whole drawing, or objects (picked in the drawing; kept, made a block or deleted) to a DWG or DXF file with what they need, its base point and insert units; `BATTMAN`, the Block Attribute Manager, edits a block's attribute tags, prompts, defaults and modes, reorders or removes them, and brings its references in line (Sync); `ATTEDIT` (`ATE`) edits a reference's attribute values, `-ATTEDIT` changes them across references by block, tag and value (with * and ? wildcards); `NCOPY` copies objects out of block references in place or by two points; `PASTEBLOCK` (Cmd+Shift+V) pastes the clipboard as a block; `SETBYLAYER` makes color, linetype and lineweight ByLayer, in blocks too |
| External references | `XATTACH` (`XA`, Insert tab): attach a DWG or DXF drawing with a full, relative or no path, as an attachment or overlay, at a picked or typed point, scaled and rotated. `IMAGEATTACH` (`IAT`): attach a GeoTIFF, TIFF, PNG, JPEG or BMP image, placed by its georeferencing (GeoTIFF tags or a world file such as `.tfw`) or by hand; pick many GeoTIFFs at once to attach them all where they belong, each on its own layer, turned off and not read: turning a layer on loads its image. `PDFATTACH`: attach a page of a PDF (at scale 1, its size in millimeters). `IMAGECLIP` (`ICL`, `PDFCLIP`): clip an image or PDF page to a rectangle or polygon. `ADJUST` (or the Properties palette) sets an image's brightness, contrast and fade, a PDF underlay's fade and monochrome, `TRANSPARENCY` whether an image's transparent pixels show what's under it; plots show them exactly, the screen closely. `IMAGEFRAME`, `PDFFRAME` and `FRAME` (with wipeouts) hide frames, show and plot them, or show them only; all kept in DXF and DWG. Each attached drawing, image or page goes on a layer of its own name. The External References palette (`XR`, `ER`) lists them all with status (Loaded, Unloaded, Not Found, Unreferenced), size, type and path, and the drawings each attachment attaches in turn; it opens a drawing in its own window, reloads, unloads, detaches and binds (Bind or Insert) drawings, and loads, unloads and detaches images, several at a time, or loads the images in view. Images are read in the background. Attached drawings draw faded; their layers come along as `NAME\|layer`, and turning them off, freezing or recoloring them is saved. Files are found again by their saved path or next to the drawing; only paths are saved. When a file has moved, the palette's Browse... picks where it is now (other missing images in that folder are found with it), and Find in Folder... repoints several images at once. `REFEDIT` on an attached drawing saves the edits to its own file (under that file's layer names), after saying what in it Oxidraft can't keep, and leaves the old file as `.bak` |
| Layers & properties | Layer Properties Manager (`LA`): new, delete, rename, current, On/Freeze/Lock, color — all undoable, for several layers at once (Cmd- and Shift-click); the ribbon layer dropdown has LT's bulb/sun/lock toggles and shows the selected objects' layer (pick another to move them there); `LAYMCUR` (Make Current) makes an object's layer current; `LAYISO` / `LAYUNISO` (lock and fade, or turn off, every other layer), `LAYOFF`, `LAYFRZ`, `LAYLCK`, `LAYULK`, `LAYON`, `LAYTHW` — also on the ribbon; the Layers panel's slide-out has `LAYWALK` (only the layers picked in its list show, restored on close unless you say), `LAYMCH`, `LAYCUR`, `COPYTOLAYER`, `LAYMRG` (merge layers into another), `LAYDEL` (a layer and everything on it) and `LAYERP` (`LAYP`, the layer settings before the last change); locked layers draw faded and can't be selected. Properties palette (`PR`, Cmd+1, or double-click an object) edits color, layer, linetype, lineweight and geometry; it docks at the left or right of the drawing area or floats (drag its title, or its Dock menu), and stays where it was put; `MATCHPROP` (`MA`); the Home tab's Properties panel sets the color, linetype and lineweight of the selected objects, or with nothing selected what new objects get (so does the Properties palette); `COLOR` (`COL`) picks from all 255 index colors, `LINETYPE` (`LT`) is the Linetype Manager (Load, Delete, Current, global scale factor), `LWEIGHT` (`LW`) the Lineweight Settings; `-COLOR`, `-LINETYPE` (?, Create, Load, Set) and `-LWEIGHT` at the command line. Kept in DWG and DXF, with loaded linetypes; transparency (0–90%) per object (ByLayer, ByBlock or a value, in the Properties palette, and for new objects) and per layer (a Layer Properties Manager column), drawn see-through and kept in DXF (as AutoCAD 2010's, which has it) and DWG; `LAYERSTATE` (`LAS`), the Layer States Manager, saves the layers' settings under a name and restores, renames or deletes them (kept in DWG and DXF); `LAYVPI` freezes the selected objects' layers in every viewport but the one picked; `VPLAYER` freezes, thaws or resets layers by name (with wildcards) in all of a layout's viewports, the selected ones, the current one or all but it, and lists a viewport's frozen layers; `HYPERLINK` (Ctrl+K) links objects to a web page or file (relative to the drawing), with a description shown when hovering; Cmd- or Ctrl-click follows the link; kept as AutoCAD's PE_URL data in DXF and DWG |
| Linetypes & lineweights | per layer (in the Layer Properties Manager) or per object, ByLayer / ByBlock through blocks; AutoCAD's standard linetypes (DASHED, HIDDEN, CENTER, PHANTOM, DOT, DASHDOT, BORDER, DIVIDE) plus any a drawing defines (complex linetypes draw their dashes, not their text or shapes); `LTSCALE` (`LTS`); LWT on the status bar shows lineweights |
| Modify | `MOVE` (`M`), `COPY` (`CO`), `ROTATE` (`RO`) and `SCALE` (`SC`) with Copy/Reference, `MIRROR` (`MI`), `STRETCH` (`S`), `OFFSET` (`O`) by distance or Through (sharp outside corners), `TRIM` (`TR`) and `EXTEND` (`EX`) in Quick mode with Shift to switch, `FILLET` (`F`) and `CHAMFER` (`CHA`) for two lines or all polyline corners, `ARRAY` (`AR`, also `ARRAYRECT`, `ARRAYPOLAR`): rows and columns or around a center, one associative array (`ARRAYASSOCIATIVITY`, or ASsociative) that `ARRAYEDIT` and the Properties palette change — its counts, spacing and angles, its source objects edited in place (Source, then `ARRAYCLOSE`), items replaced by other objects (REPlace, RESet) — that its grips change (the base moves it, the second and last items of a row or column set their spacing and count, a polar array's last item its fill angle, a path array's last item its count), path arrays divided over the path or measured along it (Method: Divide or Measure, Fill entire path), that follows its path when the path changes, and that `EXPLODE` breaks into its items, kept in DWG and DXF as a block reference (`-ARRAY` and `ARRAYCLASSIC`, the Array dialog, make plain copies), `BREAK` (`BR`) and `BREAKATPOINT`, `DRAWORDER` (`DR`: Front, Back, Above or Under objects; also on the Modify panel and the right-click menu), `TEXTTOFRONT`, `HATCHTOBACK` (new hatches go behind what they fill, attached images to the back; draw order is read from and saved to DXF and DWG), `JOIN` (`J`) into a line, arc or polyline, `LENGTHEN` (`LEN`: DElta, Percent, Total, DYnamic), `PEDIT` (`PE`): Close/Open, Join (Multiple with a fuzz distance), Width, Decurve, Reverse, and lines or arcs turned into polylines; `SPLINEDIT` (`SPE`): Close/Open, Join lines, arcs, polylines and splines to its ends (exactly: arcs stay round), Fit data (Add, Delete, Move, Close, Purge), Edit vertex (Add and Delete control vertices, Move, Weight, Elevate order), convert to Polyline, Reverse and Undo; a polyline picked becomes a spline; TRIM, BREAK and OFFSET work on ellipses, splines, construction lines and rays (trimming a construction line leaves a ray), `EXPLODE` (`X`), `ERASE` (`E`), grip editing (click or drag a grip), `BLEND` joins two objects' ends with a spline leaving each along it (Tangent, or Smooth); `CHPROP` changes objects' color, layer, linetype, lineweight or transparency at the command line, `CHANGE` (`-CH`) that or moves line ends and resizes circles to a point and gives texts a new place and text; | Selection | pick, window (left to right), crossing (right to left), click-click windows, press-drag lassos (dragged off to the right a window lasso, to the left a crossing one, which STRETCH stretches by too; Space while dragging cycles Window, Crossing and Fence), and at "Select objects:" AutoCAD's typed options: Window, Crossing, WPolygon, CPolygon, Fence, ALL, Last, Previous, Add, Remove and Undo, selection cycling (`SELCYCLE` on the status bar, Ctrl+W: a click on objects on top of each other lists them, each highlighted as you point at it, to pick the one meant, at selection prompts and at prompts for one object such as OFFSET's, TRIM's or FILLET's), selection preview, Shift to remove, noun-verb (select first, then run a command), Delete erases; `SELECTSIMILAR` (same type and layer, or what its SEttings choose); Quick Select (`QSELECT`, or `FILTER`, also in the right-click menu and the Properties palette) by object type and color, layer, linetype or lineweight, to include, exclude or append; Cmd+C / Cmd+X / Shift+Cmd+C (`COPYCLIP`, `CUTCLIP`, `COPYBASE`) and Cmd+V (`PASTECLIP`, `PASTEORIG`) copy objects with their layers and blocks, between drawings too |
| Inquiry | `DIST` (`DI`), `AREA` (`AA`) of picked points or an object (circles, ellipses, splines, polylines, arcs, hatches without their islands), `ID`, `LIST` (`LI`); `MEASUREGEOM` (`MEA`, the Utilities panel's Measure) measures a distance, a radius, an angle (of an arc, between two lines, or from a vertex), an area or a volume, one after another; `DBLIST` lists every object; `STATUS` the drawing's counts, limits, extents and modes; `TIME` when it was made and saved |
| Drafting settings | `DSETTINGS` (`DS`) and `OSNAP` (`OS`, or Object Snap Settings in the status bar's snap menu): AutoCAD's Drafting Settings — snap spacing, grid on and its spacing or adaptive, polar tracking and its increment angle, ortho, running object snaps (Select All, Clear All) and dynamic input; `PTYPE` picks among the 20 point styles and sets their size, relative to the screen or in units; `SELECTALL`, `BASE` (INSBASE) and `OOPS` (what the last ERASE erased comes back); `ISODRAFT` (or ISO on the status bar) drafts isometrically: ortho along the plane's axes, an isometric grid and snap, `ISOPLANE` (F5, Ctrl+E) to change planes, and ELLIPSE's Isocircle |

| Calculator | `QUICKCALC` (`QC`, Cmd+8, View tab's Palettes): AutoCAD's QuickCalc — an expression line with a number pad and functions, the history of what was worked out (click one to use it again), Paste value to command line, and length and angle units conversion; `CAL` works out an expression at the command line (`+ - * / ^`, brackets, `sin`, `cos`, `tang`, `asin`, `acos`, `atan`, `sqrt`, `sqr`, `abs`, `round`, `trunc`, `ln`, `log`, `exp`, `exp10`, `r2d`, `d2r`, `min`, `max`, `pi`; angles in degrees) |

| Layouts | the tabs beside Model switch to each layout (paper space): its sheet with the printable area marked, the model shown through its viewports at their scale without the layers they freeze, and what's drawn there going onto the sheet; each space keeps its own view. ### Not yet

What AutoCAD LT has that Oxidraft doesn't, yet:

- **Associative arrays:** levels (3D) and rows along a path; AutoCAD sees an array as a block reference.
- **Multileaders** gathered onto one block (`MLEADERCOLLECT`) show only the first block to AutoCAD, and multileaders saved as AutoCAD 2004 or older are LEADERs with their text or blocks.
- **Text:** MTEXT's stacked fractions show as plain text (1/2), and columns and paragraph indents (`\p`) aren't laid out; dimensions' and multileaders' representations at each scale move together.
- **Export:** DWF6 files (`EXPORTDWF` writes DWFx); WMF puts a turned or slanted picture over its bounds, unturned. `INSERTOBJ` links other files rather than embedding them as OLE objects.
- **Sheet sets** are Oxidraft's own files (.oxss), not AutoCAD's .dst, and have no subsets or sheet views.
- **Interface:** `CUI` customizes shortcuts and the Quick Access Toolbar, not the ribbon or menus; tiled and cascaded drawings are previews to pick from, not windows to work in side by side.
- **Autodesk's cloud:** `SHARE` makes a package rather than a link; Markup Assist and Traces.
- **Saved for AutoCAD in Oxidraft's own data:** dimension breaks, jogs and inspection, annotative scales and drawing settings round-trip in Oxidraft but show plain in AutoCAD. Fields naming objects come back as fields only with those objects. `SPELL` uses the system word list (macOS, Linux), so on Windows only the words you add.

- **Also not yet:** dynamic blocks' block properties table (`BTABLE`), scale actions, chained actions and base point parameters, DGN V8 files (V7 ones are read and written) and DWF6 files (DWFx ones are read).
- **AutoLISP:** DCL dialogs show images and image buttons as blank space (`start_image`, `vector_image` and `fill_image` aren't there). Like AutoCAD LT's, it has no ActiveX (`vla-`) functions and no Visual LISP editor.

Not in AutoCAD LT either, and not planned: 3D modeling and viewing (`3DORBIT`, `PRESSPULL`, `VIEWBASE` and the like), parametric constraints, the action recorder, `REGION`, `MLINE` and the layer translator.

## Install

From the [Releases page](https://github.com/protoblade/Oxidraft/releases):

- **Windows:** run `Oxidraft-<version>-windows-x64-setup.exe`. It installs for
  your user only (no admin rights), adds a Start menu entry and an uninstaller,
  and can make Oxidraft open `.dxf` files. Prefer no installer? Unzip
  `oxidraft-<version>-windows-x64.zip` and run `oxidraft.exe`.
- **macOS / Linux:** extract `oxidraft-<version>-<target>.tar.gz` and run
  `oxidraft`.

The builds aren't code-signed yet. Windows SmartScreen may warn on first run
(choose *More info* → *Run anyway*); on macOS a browser download may need
`xattr -d com.apple.quarantine oxidraft`. After that the app updates itself.

## Run from source

```bash
cargo run --release -p oxidraft-app
```

Open a file directly:

```bash
cargo run --release -p oxidraft-app -- path/to/drawing.dxf
```

Make a sample drawing to play with:

```bash
cargo run -p oxidraft-io-dxf --example demo -- demo.dxf
```

Render the UI headlessly in a few typical states (useful when reviewing UI changes):

```bash
cargo run -p oxidraft-app --example screenshots -- screenshots/
```

## Releasing

1. Bump `version` under `[workspace.package]` in `Cargo.toml`.
2. Commit, then tag and push: `git tag v0.2.0 && git push origin main v0.2.0`.

The [Release workflow](.github/workflows/release.yml) builds macOS (Apple
Silicon and Intel), Linux and Windows, and publishes
`oxidraft-<version>-<target>.tar.gz` plus a `.sha256` for each — the names the
in-app updater looks for. The updater only sees releases of a public repository.
For Windows it also builds the installer ([Inno Setup script](packaging/windows/oxidraft.iss))
and a zip, and installs, runs and uninstalls the app on the runner before
anything is published. The app icon comes from `python3 packaging/make_icon.py`.

### How a command works

Each command is a small state machine implementing `Command`
(`crates/oxidraft-commands/src/lib.rs`): it returns a `Prompt`, receives an
`Input` (point, value, keyword, selection or Enter), edits the `Document`, and
reports whether it needs more input. The `Engine` parses typed text, owns the
selection set, wraps each run in one undo transaction, and applies ortho/polar
tracking. See `line.rs` for a complete example, and `move_copy.rs` for one
that starts with "Select objects:".
Adding a command is usually one new file plus one entry in `COMMANDS`.
